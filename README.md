# VaultX — Fluid Security Vault

Official landing page and distribution hub for **VaultX**, designed & developed by **Hitansh Andraskar**.

Built with:
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui** design system
- **@paper-design/shaders-react** (Liquid Metal dynamic WebGL shader)
- **Framer Motion**

---

## 🚀 Key Features

1. **Fluid Liquid Metal Hero**: Interactive shader background with metallic visual dynamics.
2. **Liquid-Glass 'V' Logo**: Custom SVG emblem with specular light reflections and neon accents.
3. **Cross-Platform Access**:
   - 🤖 **Android**: Direct one-click download for `VaultX-Latest.apk` (located in `/public/VaultX-Latest.apk`).
   - 🍏 **iPhone & iPad**: Visual 3-step installation guide to add the web app to iOS Home Screen via Safari.
   - 💻 **Windows**: Direct link to launch the live web app (`https://vaultx-by-hitansh.netlify.app/`) with desktop PWA install guidance.
4. **Product Showcase**: Detailed breakdown of "What is VaultX?", "Why VaultX?", and core cryptographic features.
5. **Credits**: Prominently featured `Designed & developed by Hitansh Andraskar`.


## 🌐 Deploy to Vercel

### Option 1: Vercel Web Dashboard (Recommended)
1. Initialize Git repository and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial VaultX website commit"
   git branch -M main
   # Add your github remote and push
   ```
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository.
4. Click **Deploy** (Vercel auto-detects Next.js with zero configuration).

### Option 2: Deploy with Vercel CLI
```bash
npx vercel
```
Follow the interactive prompts to link and deploy immediately.
